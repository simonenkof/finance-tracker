# План разработки — Finance tracker MVP

Локальное Next.js-приложение для учёта финансов. Данные хранятся как JSON в приватном GitHub-репозитории `simonenkof/finance-tracker-data`. Без авторизации пользователей и без хостинга.

## Стек

Next.js (App Router) · TypeScript · Tailwind · shadcn/ui · Recharts

## Как устроены данные

- Рабочий файл: `data/live.json`
- Бэкапы: `backups/*.json` (по запросу)
- Восстановление копирует выбранный бэкап в `live.json`
- Валюта: RUB · даты: `YYYY-MM-DD` (без времени)

### Модель

| Сущность | Суть |
| --- | --- |
| Категории | `{ id, name }` |
| Операции | доход/расход: дата, сумма, категория, комментарий |
| Повторяющиеся | период day/week/month; автосоздание расходов при просрочке |
| Счета | имя + история снимков баланса (дата, сумма) |
| Net worth | актив/пассив + история; итог = активы − пассивы |
| Бюджеты | период с даты (2 недели / месяц / год), общий и/или категорийные лимиты |

## Экраны

1. **Операции** — CRUD доходов/расходов и повторяющихся платежей
2. **Категории** — простой CRUD
3. **Бюджет** — лимиты, потрачено/запланировано, progress bar
4. **Счета** — CRUD + линейный график баланса
5. **Net worth** — активы/пассивы + кривая истории
6. **Аналитика** — bar chart расходов по категориям; фильтры неделя / месяц / диапазон дат
7. **Данные** — сохранить в GitHub, бэкап, восстановление

Состояния: пустые списки, загрузка, ошибки API (токен / сеть / конфликт).

## Фазы поставки

1. Каркас, env, чтение/запись `live.json`, экран «Данные»
2. Категории + операции
3. Повторяющиеся платежи + автогенерация
4. Бюджет с прогресс-барами
5. Счета и net worth + линейные графики
6. Аналитика (bar + фильтры дат)
7. Бэкап/восстановление, README, полировка состояний

## Вне скоупа

Авторизация, мультиустройство, realtime, связь операций со счетами, переводы, мультивалютность, деплой.
