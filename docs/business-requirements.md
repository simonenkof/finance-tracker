# Бизнес-требования — Finance tracker

## Цель продукта

Отображение и аналитика денежных потоков.

## Пользователи

Личное пользование. Авторизация не нужна.

## Основные сценарии

- Ежедневное ведение финансовых операций.
- Планирование бюджета на 2 недели, месяц и год.
- Ручное ведение net worth всех активов.
- Просмотр аналитики трат по категориям, по неделям, по месяцам.

## Функциональные требования

### Интерфейс и хранение

- Веб-интерфейс (локальный запуск, без хостинга).
- Стек: Next.js + TypeScript + Tailwind + shadcn/ui + Recharts.
- Данные хранятся в одном приватном GitHub-репозитории (владелец создаёт репозиторий и передаёт ключи).
- Формат данных — JSON (`data/live.json`; бэкапы в `backups/*.json`).
- Работа только с одного устройства и одной вкладки.
- Валюта — рубли.
- Даты без времени (`YYYY-MM-DD`).

### Операции

- Типы: доходы, расходы, повторяющиеся платежи.
- Подписки = повторяющиеся платежи (одна сущность).
- Поля обычной операции: дата, сумма, категория, комментарий.
- Все сущности можно создавать, редактировать и удалять.

### Повторяющиеся платежи

- Период: `day` | `week` | `month`.
- При наступлении срока автоматически создаются обычные расходные операции (expense).
- Поля: период, дата старта, сумма, категория, комментарий, активность, дата последней генерации.

### Счета

- CRUD: создание, редактирование, удаление.
- Счета «глупые», как net worth: не связаны с операциями.
- У счёта есть история баланса (ручные снимки: дата, сумма), доступная в виде линейного графика.
- Снимок баланса / net worth: дата, сумма, имя (имя — у сущности счёта или позиции net worth).

### Net worth

- Активы и пассивы (`asset` | `liability`).
- Есть история снимков (дата, сумма), доступная в виде линейного графика.
- Итог net worth = сумма активов − сумма пассивов (по последним снимкам).

### Категории

- Создаёт пользователь вручную.
- Без подкатегорий и без автоматических привязок.

### Бюджет

- Лимиты: общий и/или по категориям (одна или несколько категорий на лимит).
- Отображение максимально простое: потрачено / запланировано и прогресс-бар.
- Период бюджета выбирает пользователь с любой даты (длительность: 2 недели, месяц или год).

### Аналитика

- Столбчатые диаграммы расходов по категориям.
- Линейные графики историй балансов (счета, net worth).
- Фильтры периода: неделя, месяц, произвольный диапазон дат (только даты, без времени).

### Бэкап

- Отдельный бэкап по запросу в тот же GitHub-репозиторий (не то же самое, что обычное сохранение рабочих данных).
- Восстановление из бэкапа.
